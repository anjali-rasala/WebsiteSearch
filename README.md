# Website Search

A simple website search application built using HTML, CSS, Bootstrap, and JavaScript.

## Features

* Search for information using keywords
* Displays search results dynamically
* Loading spinner while searching
* Responsive design using Bootstrap
* Globe logo

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Project Structure

```text
WebsiteSearch
│
├── index.html
├── style.css
├── script.js
├── globe.png
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a keyword in the search box and press Enter.

Created as a web development project to practice HTML, CSS, Bootstrap, JavaScript, and Git/GitHub.
